# 뽀모도로 타이머 계획 작업 지침

## 배경
이 프로젝트(`my-blog`)는 마크다운 기반 블로그 + 미니 웹앱 포트폴리오다. 사용자가 새 웹앱을 요청하면 Plan → Build → Review → Embed 순서로 진행하며, 지금은 Plan 단계다. 프로젝트 루트의 `CLAUDE.md`를 참고해도 좋다. 참고로 `/apps/2048/`에 이미 완성된 앱과 그 `spec.md`가 있으니 구조를 참고해도 된다(단, 이 앱 자체를 건드리지는 말 것).

## 요청받은 웹앱
뽀모도로(Pomodoro) 타이머: 집중 시간(work)과 쉬는 시간(break)을 카운트다운하는 타이머. **집중 시간과 쉬는 시간 길이를 슬라이더(input type="range")로 사용자가 직접 조정할 수 있어야 한다.**

## 해야 할 일
1. `C:\Users\SNOO\Desktop\my-blog\apps\pomodoro\spec.md` 파일에 구현 계획을 작성한다. 다음 내용을 반드시 포함할 것:
   - **기능 요약**: 카운트다운 타이머(분:초 표시), 시작/일시정지/리셋 버튼, 집중(work) 세션과 쉬는(break) 세션이 번갈아 진행되는 방식, 세션이 끝나면 다음 세션으로 자동 전환되는지 여부(및 그때 알림 방식 — 소리/브라우저 알림/화면 표시 등 무엇을 쓸지 결정), 현재 몇 번째 세션인지 표시할지 여부.
   - **슬라이더 요구사항**: 집중 시간 슬라이더와 쉬는 시간 슬라이더 각각의 범위(예: 집중 5~60분, 쉬는 1~30분 등 합리적인 기본값과 범위를 정할 것)와 단위(분 단위 등), 슬라이더 값을 옆에 숫자로 실시간 표시하는 방법, **타이머가 실행 중일 때 슬라이더를 조정하면 어떻게 되는지**(다음 세션부터 반영되는지, 즉시 반영되는지 등 — 명확히 정할 것), 슬라이더 값 변경 시 남은 시간 표시가 어떻게 갱신되는지.
   - **파일 구조**: `/apps/pomodoro/` 폴더 안에 어떤 파일을 만들지(예: index.html, style.css, timer.js 분리 여부 등) — 근거와 함께 결정할 것.
   - **핵심 로직 설계**: 타이머 카운트다운을 어떻게 구현할지(예: `setInterval`로 매 초 갱신하되 실제 경과 시간은 타임스탬프 비교로 계산해 탭이 백그라운드로 가서 setInterval이 느려져도 시간이 안 밀리게 하는 방법 등), 시작/일시정지/리셋 상태 전환, work↔break 세션 전환 로직, 슬라이더와 타이머 상태의 상호작용.
   - **스타일**: 큰 숫자로 남은 시간을 표시하는 타이포그래피 중심 레이아웃, 집중/쉬는 시간을 시각적으로 구분하는 방법(배경색 전환 등), 슬라이더 UI 스타일, 반응형 레이아웃(모바일에서도 잘 보이도록).
   - **외부 의존성**: 라이브러리는 최소화한다. 이 앱은 순수 JS로 충분히 구현 가능하므로 라이브러리 없이 설계할 것을 강력히 권장한다(불가피한 경우에만 CDN 사용 근거를 명시).
2. 계획만 작성하고 실제 코드는 작성하지 않는다. 구현(Build)은 이후 별도의 서브에이전트가 담당한다.

## 제약
- `spec.md` 한 파일만 만든다. 그 외 어떤 파일도 만들거나 수정하지 않는다.
- 프로젝트의 다른 파일(`build.js`, `lib/`, `public/`, `posts/`, `apps/2048/` 등)은 절대 건드리지 않는다.

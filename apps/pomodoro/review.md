# 뽀모도로 타이머 검증 결과 (review.md)

## 검증 방법
- `spec.md`와 `index.html` / `style.css` / `timer.js` 코드를 전체 정독했다.
- 프로젝트 기존 프리뷰 서버(포트 5173)는 건드리지 않고, 이 세션에서만 쓰는 정적 파일 서버를 별도 포트(5180)에 Node 스크립트로 직접 띄워 `apps/pomodoro/` 3개 파일만 서빙했다(스크래치패드에 임시 서버 스크립트 작성, `preview_start`/`launch.json`은 건드리지 않음). `file://` 직접 열기는 이 브라우저 도구에서 "정적 스냅샷"으로만 렌더링되어 JS가 실제로 동작하지 않는 것을 확인했기 때문에 사용하지 않았다.
- 실제 브라우저(Claude Browser 도구)로 열어 클릭/슬라이더 조작/모바일 리사이즈를 수행하고, 콘솔·네트워크 로그와 `document`/DOM 상태를 JS로 직접 조회해 검증했다.
- 세션 자동 전환은 실제로 25분/5분을 기다리는 대신, 페이지의 전역 `Date.now`를 일시적으로 monkey-patch해(예: `Date.now = () => 원래시각 + 11분`) 다음 tick에서 `remaining <= 0`이 되도록 만들어 실제 코드 경로(`handleSessionEnd`)가 그대로 실행되는 것을 재현했다. 이는 내부 상태를 직접 조작한 것이 아니라 "시간이 그만큼 흘렀다"는 조건만 만들어준 것이므로, 실제 장시간 대기와 동일한 코드 경로를 검증한 것이다. 확인 후 `Date.now`는 원상 복구했다.
- 서버는 PID를 직접 지정해 `kill <pid>`로 종료했다(광범위한 `taskkill` 등은 사용하지 않음). 기존 5173 서버는 시작·종료 어느 쪽도 건드리지 않았고 검증 종료 시점에도 정상적으로 계속 LISTENING 상태였다.
